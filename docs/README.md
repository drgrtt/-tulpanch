# FLOWER SHOP — DESIGN PACK

**Pack version:** 0.5  
**Status:** production-planning draft  
**Purpose:** turn the existing concept/GDD into implementable systems.

## Files

1. `00_MASTER_GDD_v0.4.md` — current master concept and onboarding.

3. `01_PROGRESSION_ECONOMY.md` — first-shop progression, numerical economy, recipes, costs and pacing.
4. `02_GAME_SYSTEMS.md` — customers, workers, stack physics, object states, save/offline and fail states.
5. `03_WORLD_AND_CONTENT.md` — Shop 1 map, zones, expansion logic and content roadmap for later regions.
6. `04_PRODUCTION_BIBLE.md` — visual, UI, animation, audio, haptics, technical constraints, analytics and QA.
7. `05_DEPENDENCY_MATRIX.md` — why each feature exists, what unlocks it and what bottleneck it creates.

## Important note on numbers

All economy values in this pack are **Balance Draft v0.1**, not final truth.

They are designed to:
- make the first session playable without waiting;
- create a meaningful purchase every 1–3 minutes early;
- create a meaningful expansion roughly every 8–15 minutes early;
- keep the first shop finishable without ads or premium currency;
- make each upgrade solve a bottleneck the player has already felt.

The prototype should log real throughput and completion times. Values must then be retuned from playtest data.
